# Algorithm Visualizer (Java)

A desktop application built in Core Java and Java Swing that visually demonstrates how various sorting algorithms operate in real-time. 

This project was developed as a First-Year B.Tech Capstone to bridge the gap between abstract algorithmic theory and tangible execution.

## 🚀 Features
* **Real-time Animation:** Watch algorithms sort data step-by-step.
* **Dynamic Datasets:** Generates randomized bar charts for sorting.
* **Modular Design:** Built using the Strategy Design Pattern, making it trivial to plug in new algorithms.
* **Multi-threaded:** Ensures the UI remains responsive while the intensive sorting loops run in the background.

## 🛠️ Technologies Used
* **Language:** Java SE
* **GUI Framework:** Java Swing & AWT
* **IDE:** Visual Studio Code

## 🧮 Algorithms Currently Implemented
1. Bubble Sort
2. Selection Sort
*(More to come including Merge Sort, Quick Sort, and Insertion Sort)*
